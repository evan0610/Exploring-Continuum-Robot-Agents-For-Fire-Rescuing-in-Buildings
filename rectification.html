P1 / Current scope / 外推缩比喷水和口罩运输不能说明灭火、供氧、耐热或现场救援效果。将缩比条件放在首屏与视频旁；若继续研究，给热/烟/负载/流量协议。；验收：任务说明不含未经测试的救援效果。
P2 / 首屏 / 论文长标题完整长标题占据大量首屏空间，主要实体证据在下方。显示短标题“Continuum Rescue”，全称放副标题；首屏加入带标注的本体与任务图。；验收：390px 可看到任务和演示入口，长题名不支配布局。
P2 / Awards / 与结果比例奖项具有来源，但不能替代控制性能、重复性或自治证据。保留认可模块，补独立性能栏目：定向误差、喷水命中、运输成功和重复次数。；验收：没有用获奖推导技术有效性。
